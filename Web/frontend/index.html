💡 신뢰 지수 산출 기준

보안 신뢰 지수는 100점에서 시작하여 비정상 패킷 또는 핵 행위 감지 로그 발생 시 차감되는 구조입니다.

  • 클린 (90점 이상): 비정상 행동 감지 이력이 전혀 없는 신뢰할 수 있는 계정입니다.
  • 주의 (30 ~ 70점): 비정상 조준선 또는 간헐적 네트워크 속도 초과 감지로 집중 모니터링 대상입니다.
  • 제재 (30점 미만): 확실한 악성 프로그램 사용 기록으로 접속이 완전 제한 및 격리 조치됩니다.

🙋 고객지원 및 자주 묻는 질문 (FAQ)

Lyra Shield는 게임 클라이언트로부터 수집되는 플레이어의 행동 텔레메트리(조준선 각도 변화, 이동 속도 벡터, 체력 상태 변화 등)를 백엔드로 전송하고, AI 추론 모델을 통해 정상 범위를 벗어난 비정상 속도핵, 에임 보정(Aim Assist), 비정상 시야 확보(ESP) 여부를 99.7%의 높은 정확도로 감지해 냅니다.

보안 클라이언트의 웹 브라우저 간 프로토콜 등록이 완료되어야 정상 런칭이 작동합니다. 압축 해제된 게임 경로에서 Register_LyraProtocol.bat 배치 파일을 찾은 다음, 반드시 [마우스 우클릭 -> 관리자 권한으로 실행]을 하여 1회 등록 절차를 밟아주시기 바랍니다.

보안 점수가 위험 범위인 30점 이하로 급락하는 경우 시스템 가이드에 따라 제재 처리됩니다. 오탐지가 의심되는 경우 플레이 도중 발생했던 시나리오 정보와 로그인 아이디를 작성하여 고객지원 메일 또는 문의 폼을 통해 접수해 주시면 보안 검증 로그를 다시 확인한 후 수동으로 조치해 드립니다.

🛡️ AI Shield 보안 시스템 소개

🧠

머신러닝 기반 실시간 분석

플레이어의 조준선 회전(Aim), 이동 속도(Speed), 피해량 및 이동 궤적 데이터를 실시간 수집하여, 서버측 AI 탐지 엔진이 머신러닝 패턴 분석을 통해 핵 사용 여부를 즉시 판단합니다.

🔒

클라이언트 데이터 무결성

언리얼 엔진 5 클라이언트와 백엔드 간 전송되는 모든 텔레메트리 패킷은 암호화되며, 패킷 위조 및 가로채기 차단 기술(Integrity Check)이 내장되어 있습니다.

⚡

즉각적인 자동 제재 (Auto-Kick)

치트 행위 감지 시 보안 신뢰 점수가 30점 미만으로 급락하며, 탐지 즉시 게임 세션에서 강제 퇴출(Kick) 및 계정 차단 프로세스가 연동됩니다.

📊 관리자 모니터링 가이드

🖥️

실시간 의심 유저 모니터링

보안 점수가 비정상적으로 낮은 유저들은 실시간 감시 목록에 자동 등록됩니다. 관리자는 대시보드에서 해당 플레이어의 핵 사용 확률과 최근 의심 행동 유형(예: 에임봇 패턴, 비정상 속도)을 즉시 한눈에 확인할 수 있습니다.

🔍

상세 게임 로그 분석

수집된 텔레메트리 원본 로그 조회를 통해, 실제 클라이언트의 패킷 세부 항목(SpeedHack 여부, Aim 보정 여부, 무적 모드 여부 등)을 정밀 대조하여 오탐지 여부를 최종 검증합니다.

🔨

보안 점수 기반 즉각 제재

AI 신뢰도와 누적 탐지 횟수를 가공해 산출한 클린 점수가 위험 수준에 도달한 대상은 관리 대시보드에서 원클릭으로 서버 세션 강제 차단 및 영구 제재 조치할 수 있습니다.
