🙋 고객지원 및 자주 묻는 질문 (FAQ)

Lyra Shield는 게임 클라이언트로부터 수집되는 플레이어의 행동 텔레메트리(조준선 각도 변화, 이동 속도 벡터, 체력 상태 변화 등)를 백엔드로 전송하고, AI 추론 모델을 통해 정상 범위를 벗어난 비정상 속도핵, 에임 보정(Aim Assist), 비정상 시야 확보(ESP) 여부를 99.7%의 높은 정확도로 감지해 냅니다.

보안 클라이언트의 웹 브라우저 간 프로토콜 등록이 완료되어야 정상 런칭이 작동합니다. 압축 해제된 게임 경로에서 Register_LyraProtocol.bat 배치 파일을 찾은 다음, 반드시 [마우스 우클릭 -> 관리자 권한으로 실행]을 하여 1회 등록 절차를 밟아주시기 바랍니다.

보안 점수가 위험 범위인 30점 이하로 급락하는 경우 시스템 가이드에 따라 제재 처리됩니다. 오탐지가 의심되는 경우 플레이 도중 발생했던 시나리오 정보와 로그인 아이디를 작성하여 고객지원 메일 또는 문의 폼을 통해 접수해 주시면 보안 검증 로그를 다시 확인한 후 수동으로 조치해 드립니다.
